# Aspose.HTML for Java Examples

This repository contains executable Java examples for [Aspose.HTML for Java](https://products.aspose.com/html/java/). The examples accompany the product documentation and demonstrate HTML, SVG, EPUB, MHTML, Markdown, accessibility, data extraction, message handling, and format conversion scenarios.

## Main Example Areas

- `Getting_Started` — licensing, metered licensing, and a basic HTML-to-PDF conversion.
- `Working_with_HTML_Documents` — document creation, editing, environment configuration, and saving.
- `Converting_Between_Formats` — conversion between HTML, SVG, EPUB, MHTML, Markdown, XPS, images, and PDF.
- `Data_Extraction` — CSS selectors, XPath, navigation, and downloading linked content.
- `Web_Accessibility` — accessibility and color-contrast checks.
- `Advanced_Programming`, `Message_Handlers`, `Working_with_HTML_Templates`, `Markdown`, and `How_to_Articles` — focused API scenarios and documentation snippets.
